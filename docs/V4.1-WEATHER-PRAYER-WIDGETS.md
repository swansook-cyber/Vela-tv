# Vela TV Launcher V4.1 — Weather and Prayer Times

Status: Development. Base: v4.0.0. No production changes.

## Guest-facing Home
- Two independently toggleable native Home panels: Weather and Five Daily Prayers.
- Both default OFF for upgrades, preserving the exact V4.0.0 Home until explicitly enabled.
- On-screen panel selection must not steal D-pad focus from the existing app grid.
- Weather: current temperature, condition, location, observation timestamp.
- Prayer: Fajr, Dhuhr, Asr, Maghrib, Isha; next prayer and countdown; dates and timezone explicit.
- No invented sample times displayed as live values. Missing or stale data must be labeled.

## Settings
- Weather widget ON/OFF, Prayer widget ON/OFF independently.
- Store flags locally and persist across reboot.
- Default location configurable (initial Krabi); no requirement for continuous GPS.
- Prayer calculation method, Asr madhhab and minute adjustments configurable.
- Confirm calculated times against a trusted local Thai mosque or authority before enabling alerts.
- No audio/adhan/notification in V4.1 unless separately approved.

## Technical constraints
- Use a documented weather API (candidate: Open-Meteo) and a documented prayer-time source; audit API terms, rate limits and Thai locale accuracy.
- Avoid adding privileged permissions. Network permission required only when live API integration is implemented.
- Cache last valid response and expose update timestamp; never mislabel stale prayer times as today's.
- Use existing app theme, no full-screen overlay, no launcher replacement migration.
- Validate TCL Android TV 11 D-pad/OK/Back and power cycle.

## Release gate
- CI APK build PASS, source review, real-device QA, rollback to V4.0.0.
- Do not merge main, publish to Vela App Store, or alter existing V4.0.0 installation without explicit approval.
